# Change Card: v7.2.156 Release-Gate Publication

## Scope

This card updates the repository publication gate for the already accepted CPA
v7.2.156 compatibility candidate. It does not alter runtime request behavior,
OAuth handling, TLS policy, headers, body serialization, or production config.

## Baseline and candidate

- Upstream baseline: `d1a024e9400bc65bd78ccd908945cf2eacc2835e` (`v7.2.156`).
- Candidate merge: `2ec017db0fd0505a656846c83d369462b6b74fe0`.
- Candidate branch: `release/claude-compatibility-v7.2.156-20260910`.
- Local release-gate branch: `feat/release-gate-v7.2.156-20260910`.

## Allowed changes

- Pin the compatibility workflow baseline to the upstream v7.2.156 commit.
- Replace the stale release allowlist with the exact non-artifact candidate path
  manifest in `docs/deployment/CLAUDE-COMPATIBILITY-RELEASE-PATHS.txt`.
- Keep experiment evidence outside the source repository and ignore `/artifacts/`.
- Update the release manifest to identify the v7.2.156 candidate.

## Prohibited changes

- No runtime or wire behavior changes.
- No OAuth, proxy, credential, model, tool, prompt, ID, TLS, retry, or pool changes.
- No deletion of local evidence files; only their Git index entries are removed.

## Verification

- Local release preflight must return `RELEASE_PREFLIGHT=PASS`.
- Candidate path guard must match every final-tree path changed from the upstream
  baseline and no artifact path.
- `git diff --check` must return exit status 0.
- GitHub Actions must pass baseline focused tests, modified focused tests, and the
  source-diff guard before merge.
- An independent rollback copy must restore the pre-card tree exactly.

## Rollback

Restore the pre-card commit and re-add the removed artifact paths only in a
separate evidence copy. Do not alter the local evidence tree.
